# buy-or-rent · 买房还是租房？

用 150 年、18 国的历史数据，把"买房还是租房"从一道依赖未来预测的算术题，
变成一个输出概率的估算问题。

**核心思路**：决策变量分三层——租售比、利率、税费等在决策时刻**直接可观察**；
未来房价涨幅**半可预测**（被期初估值条件化）；投资收益、通胀体制**不可约不确定**
（用历史分布代言）。算法先解出"买房打平需要的涨幅 g\*"，再回答
"这个涨幅在 1870 年以来的所有历史窗口中出现过百分之几"。

## 快速开始

```bash
pip install pandas numpy matplotlib scipy openpyxl
bash data/download.sh                     # 下载 JST 宏观历史数据库(不入库)
python3 analysis/stylized_facts.py        # 复现六个典型事实, 生成图表与派生数据
python3 analysis/algorithm_figures.py     # 算法输出总览图

# 估算你自己的情况(示例: 租金收益率1.8%, 本市历史常态2.2%, 按揭4%, 持有10年)
python3 -m buyrent.cli --rent-yield 0.018 --ry-typical 0.022 \
    --mort-rate 0.040 --down 0.30 --hold 10
```

## 主要发现（详见 [论文初稿](paper/paper.md)）

- 1870–1950 年 18 国真实房价年涨中位数仅 **+0.3%**；战后升至 +2.3%，全期 +1.2%。
- 住房长期真实总回报 ≈7%/年，与股票相当——但其中约 5 个百分点来自**租金**，
  涨价只贡献约 1–2 个百分点。买房赚的可靠部分是省下的租金。
- 期初租售比偏离**负向预测**未来十年房价（t≈−5），但 R²≈2%：
  方向可靠、力度温和——所以诚实的答案只能是概率，不是点估计。
- 历史上所有"国家×10年"窗口中，真实房价年化涨幅 ≥2% 的只有 38%，
  ≥4% 的只有 18%；高估值起点之后十年下跌的概率为 42%。
- 经验法则：按揭 4.5%、首付三成时，**租金收益率 ≈4.5% 是买房不靠涨价
  也划算的分水岭**；持有期不足 5 年时交易成本几乎注定租房更优。
- **2026 年中国**（论文第 8 节）：房价下跌 + 按揭 3.1% + 居民投资收益率塌缩，
  买租天平较 2021 大幅回摆——二线省会（租金收益率 ≥2.3%）打平只需历史平均涨幅；
  一线金融账回到接近中性（胜率 45–56%）；三四线按耐用消费品逻辑对待；
  日本路径（1990 后十年年化 −2.2%）是所有城市共同的左尾。
  含分城市 × 分年龄 × 分收入的建议矩阵。

## 仓库结构
